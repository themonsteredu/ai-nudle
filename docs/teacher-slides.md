이미지는 현재 기존 시연 자료를 사용합니다. 아래 문장은 새 이미지를 제작할 때 사용할 프롬프트입니다. 글자는 이미지에 생성하지 않고 웹 슬라이드에서 에스코어드림으로 표시합니다.

## 1. 맛있는 생각을 식품으로 만드는 사람

16:9 실사 교육용 사진. 한국 식품개발 연구실에서 성인 연구원이 전자저울로 분말 재료를 계량하고 실험 노트에 기록하는 모습. 위생복과 위생모 착용. 시식컵과 소량의 분말 재료, 따뜻한 아이보리와 오렌지 포인트, 자연스러운 조명. 왼쪽은 인물과 실험도구, 오른쪽은 여백. 글자·상표·캐릭터 없음.

## 2. 아이디어가 바로 제품이 되지는 않아요

16:9 실사 편집 사진. 식품 신제품 기획 테이블에 무지 제품 샘플, 스케치 노트, 여러 분말과 작은 시식컵이 놓여 있고 성인 연구원 두 명이 아이디어를 이야기한다. 깨끗한 식품 연구실, 아이보리·브라운·오렌지 색감. 읽을 수 있는 글자나 로고 없이, 제품 아이디어가 시제품이 되는 장면.

## 3. 맛뿐 아니라 품질도 확인해요

16:9 실사 사진. 식품 연구실의 소량 시제품 컵과 뒤편 유리 너머 위생적인 시험 생산라인이 한 화면에 보인다. 전경에는 밀봉 포장 샘플과 검사 도구. 위생복을 입은 성인 연구원. 제조공정 설명도나 글자 없이, 시제품에서 품질검사로 이어지는 실제 연구 분위기. 아이보리와 오렌지 포인트.

## 4. 배합하고, 맛보고, 기록하고, 수정해요

16:9 실사 교육용 사진. 동일한 컵 세 개에 조금씩 다른 색의 국물, 작은 전자저울, 분말 소분 용기와 연필이 놓인 깨끗한 테이블. 성인 연구원의 손이 컵 하나의 계량값을 노트에 기록한다. 글자와 숫자는 보이지 않게, 정돈된 실험 구도, 따뜻한 아이보리와 오렌지 색감, 위생적인 개별 스푼.

## 5. 꼼꼼한 관찰과 협력이 필요해요

16:9 실사 사진. 식품개발 연구원, 품질검사 담당자, 생산 담당자, 패키지 기획자가 무지 라면 시제품을 두고 회의하는 모습. 다양한 성별의 성인 네 명, 실제 연구실 회의 공간, 단정한 복장, 자연스러운 표정. 글자·로고·과장된 제스처 없이 협업이 보이는 장면. 아이보리 배경, 오렌지 포인트.

## 6. 오늘은 두 가지 방법으로 연구해요

16:9 실사 탑뷰 사진. 테이블 왼쪽에는 기본 육수분말과 마늘·양파분말 작은 용기, 오른쪽에는 상표 없는 시판 스프 봉투와 치즈·카레분말. 가운데 전자저울과 국물 연습용 작은 컵, 아래에는 라면 시식용 작은 그릇 두 개. 모든 식재료가 위생적으로 분리된 정돈된 구도. 글자·로고 없음, 크림·오렌지·브라운 색감.

## 7. 친구 컵을 맛보기 전에 확인해요

16:9 실사 교육용 사진. 교사가 식품 포장 뒷면 표시를 확인하며 학생에게 시식 전 주의사항을 안내하는 손 중심 장면. 테이블에 학생별로 분리된 개인 스푼과 작은 시식컵, 뜨거운 물은 교사 쪽에 위치. 얼굴은 식별되지 않게. 포장의 글자·상표는 읽히지 않게, 차분한 아이보리와 오렌지 색감, 안전하고 위생적인 분위기.
