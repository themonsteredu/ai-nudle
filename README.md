# 라면 R&D 연구소

식품개발연구원 직업체험을 위한 2차시 반응형 웹앱입니다. 학생은 라면 제조공정을 살펴본 뒤 스프 배합 실험을 4회 진행하고, 실제 시식 결과를 반영해 최종 제품과 라벨을 완성합니다.

## 수업 흐름

### 1차시

1. 식품개발연구원 직업 이해
2. 라면 제조공정 체험
3. 스프와 건더기의 역할
4. TEST R-01 배합·시식
5. TEST R-02 배합·시식

### 2차시

1. TEST R-03 배합·시식
2. TEST R-04 배합·시식
3. 4개 레시피 비교
4. BEST RECIPE 선정
5. 최종 스프 계량과 제품 라벨 제작
6. 실제 제품 포장

## 주요 기능

- 교사 설정 데이터 기반 스프·건더기 재료 렌더링
- 재료별 투입량, 조절 단위, 단가, 알레르기, 사진 관리
- 4회 배합과 시식 메모·태그 저장
- 레시피 비교와 최종 사리면 기준 자동 확대 계산
- 학생 수에 따른 사용 원가·준비비용·준비물 자동 계산
- A4 학생 라벨 모아찍기
- 수업지도안, 체크리스트, 원가표, 실험 기록지 인쇄/PDF
- D1 기반 설정·학생 기록 저장, R2 기반 재료 사진 업로드
- 모바일·태블릿·PC 반응형 UI

## 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm ci
npm run dev
```

데이터베이스 스키마를 변경한 경우:

```bash
npm run db:generate
```

## 기술 구성

- Next.js 16 / React 19
- Vinext / Cloudflare Workers
- Cloudflare D1 / R2
- Drizzle ORM
- TypeScript

학생 화면은 `/`, 교사용 관리센터는 `/teacher`에서 열립니다.
