# 라면 R&D 연구소 홍보영상

- `ramen-rd-lab-promo.mp4`: 1920×1080, 30fps, 약 53초. 배경음악과 하단 자막이 들어 있습니다.
- 실제 앱 화면을 녹화해 자막과 함께 편집했습니다. 담긴 화면은 연구원 등록, 라면 제조 공정 미션, 스프 배합 LAB, 시식 기록, BEST 레시피 선택, 제품 라벨, 교사용 원가 자동계산, A4 라벨 모아찍기입니다.
- 화면에 나오는 학생 이름과 기록(김연구, 이하늘 등)은 녹화용 더미 데이터입니다. 실제 학생 정보는 들어 있지 않습니다.
- `ramen-rd-lab-promo.srt`: 자막 파일입니다. 유튜브 등에 따로 올릴 때 씁니다.
- `source/`: 영상을 다시 만들 때 쓰는 녹화·편집 스크립트입니다. 앱 배포에는 포함되지 않습니다.
  - `rec.mjs`, `go2.mjs`: Playwright로 앱 화면을 녹화합니다. `/api` 응답은 브라우저 안에서 더미 데이터로 바꿔 줍니다.
  - `compose.html`, `render.mjs`: 편집 화면을 프레임 단위로 렌더링합니다.
  - `music.py`: numpy로 직접 합성한 배경음악입니다. 저작권 걱정이 없습니다.
